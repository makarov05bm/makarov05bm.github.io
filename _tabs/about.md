## About Me

I'm **Oussama Messaoudi**, an Application Security researcher focused on finding and understanding vulnerabilities across modern application and cloud environments.

My main areas of interest include:

- **Web & API Security**
- **Cloud Security** — AWS, Azure, and GCP
- **Application & Container Security**
- **Kubernetes Security**
- **Smart Contract Security**
- **Penetration Testing & Red Teaming**
- **Secure Code Review**

I enjoy building security tools, researching vulnerabilities, and creating practical labs to understand how seemingly small security issues can be chained into larger attack paths.

This blog is where I document my **security research, technical write-ups, vulnerabilities, experiments, and projects**.
